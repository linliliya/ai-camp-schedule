# 本地 SOP 知识库

在本机阅读、编辑和检索 `../AI编程SOP/` 下的 Markdown 原文。左侧目录、正文、右侧大纲和编辑工具沿用飞书式工作区习惯，文件保持普通 Markdown，方便 AI 和文本编辑器直接维护。

## 打开

Windows 双击 `启动本地SOP.cmd`，或在项目根目录运行：

```powershell
.\local-sop\start.ps1 -Open
```

地址为 `http://127.0.0.1:8901`。服务仅监听本机，无需登录飞书或训练营账号。首次安装需要 Node.js 24 和 Python 3.10+；前端打包后运行只需要 Python，静态资源及字体从本地读取。

首次手动安装与构建：

```powershell
cd local-sop
npm ci
npm run build
python -X utf8 server.py
```

端口占用时使用 `start.ps1 -Port 8903`。服务 PID 和日志位于 `.state/`，停止时先核对 PID 对应本服务，再结束该进程。运行期间可关闭启动窗口，后台服务会继续运行。

## 使用与数据位置

- **原文与附件：** 项目 `AI编程SOP/`。阅读、搜索不改写原文；图片和视频保持原有相对路径。
- **编辑：** 点击编辑，可用标题、列表、引用、表格等排版工具，也可切到 Markdown 源码。点击保存或按 Ctrl+S 后写入原文。
- **草稿：** 未保存内容保留在当前浏览器的本机存储，重新打开文档可恢复；遇到保存失败也保留输入。
- **历史：** 每次保存前备份原始文件字节至 `local-sop/.state/history/`。更多菜单中可预览并恢复；恢复本身也会备份当前版本。
- **外部 AI 修改：** AI 直接编辑 Markdown 即可。阅读页面会定期读取变化；编辑期间遇到外部修改，保存返回冲突并提供新旧内容对照，避免直接覆盖。
- **检索：** Ctrl+K 打开全文搜索，支持中文及多个空格分隔的关键词。搜索直接读取最新文件，收件箱内容也可检索。
- **收件箱：** 新建零散记录保存在 `AI编程SOP/收件箱/`，可把文件交给当前聊天中的 AI 整理。页面没有接入付费 AI 服务，也不会假装已自动调用模型。
- **飞书同步：** 使用“复制正文”复制富文本，或导出 Markdown，再由用户手动粘贴/导入飞书。系统不自动操作飞书、团队数据库或 GitHub。

复制正文便于保留文字排版；图片、视频等附件需要在飞书中另行核对和上传。导出功能保存 `.md` 原文，相对路径附件仍在原文件夹，移交资料时请一起保留。

建议将整个 `AI编程SOP/` 与 `.state/history/` 一起纳入你自己的本地备份；它们分别包含正式原文与修改历史。

## 给 AI 的入库方式

可以直接告诉 AI：

> 请读取 `AI编程SOP/维护与入库/本地SOP维护规范.md`，把 `AI编程SOP/收件箱/文件名.md` 的内容整理进我指定的 SOP。先列出冲突和新增话术，按已有结构修改本地 Markdown；保留图片相对路径与未修改段落，不操作飞书，不执行 Git 提交、推送或发布。

SOP 的文字更新和 App 排期配置是两个层次。修改文档不会擅自生成新的手机通知；需要更新提醒节点时，明确安排后同步共享排期并重新打包 App。

## 检查

```powershell
python -X utf8 -m unittest discover -s tests -p 'test_*.py' -v
npm run build
```

后台测试仅使用临时目录，不改真实 SOP。前端交互检查使用单独夹具目录及端口，正式资料初始页面只做阅读验证。
