# 原生安卓 APK 验证记录

日期：2026-10-19（Asia/Shanghai）。实现方案已由用户确认。

## 实现范围

原生 Kotlin / Jetpack Compose / Material 3 应用，最低 Android 8.0、目标 Android 15，包名 `cn.aurange.schedule`，版本 1.0.0。保留网站风格并提供今日、营期、设置和任务详情。网站仍负责管理营期，手机与网站共用账号、排期和完成记录。

SOP JSON 从现有网站自动导出，原有任务标识与云端 RPC 不变。会话使用 Android Keystore AES-GCM 加密，缓存与登录信息不参与云端备份或设备迁移。权限撤销、登录过期、退出时清理本机数据与提醒；暂时断网保留只读缓存。任务修改使用界面显示的版本，后台同步不能替换该版本来绕过冲突检查。

提醒默认每日 09:00 汇总、明确时刻提前 15 分钟，均按北京时间，可调整。24:00 跨至次日；模糊时间不猜测。支持本机一次性提醒、通知测试、通知点击进入任务、重启恢复、精确闹钟授权检查与拒绝后的降级。前台每 30 秒刷新，后台 WorkManager 根据系统调度同步。

飞书资料通过限定到飞书包名的 Intent 优先打开，失败后使用 AppLink，再失败则交给浏览器。其他 HTTPS 资料使用浏览器。

## 自动化与模拟器证据

- `npm test`：19 项通过，含原有数据库、权限和 UI 回归，以及 Android SOP 导出一致性。
- `testDebugUnitTest`：13 项通过。覆盖月末/闰年筹备、4096 种休息周组合、稳定任务键、第 1 周排除回顾、第 7/12 周规则、结营后跟进、逾期范围、上海时区、提前提醒、午夜跨日、手动提醒覆盖、已完成抑制与防重复。
- 跨语言对照：使用网站实际 `campWeeks`、`weekTasks`、`taskKey` 生成 24 组输入，逐项比对安卓阶段边界、阶段类型与每一个任务键；通过。测试夹具生成在 build 目录，不打入 release APK。
- 针对同步刚好发生在闹钟时刻的回归：先复现尚未送达的汇总被重建丢弃，再修复为保留近期未送达的实际事件。验证已送达事件、设置变更、超过一小时的旧提醒与午夜维护不会错误重放。
- `lintDebug`：无问题。使用 AGP 8.7.3 避免 8.7.2 对精准闹钟权限的已知误报；同步写入会话/闹钟状态位于 IO 线程，用于保证接收器结束前落盘。
- Android 15 模拟器运行 7 项设备集成测试：Keystore 加密与缓存重载、退出清理、旧闹钟完成状态复核、通知真实打开 MainActivity、云端访问校验及捕获版本、权限撤销、离线保留/失效刷新令牌清理、退出与在途同步竞争。测试使用本地替身传输，未向线上写入测试数据。
- `scripts/verify-android-background.ps1`：安装调试应用与测试 APK，创建 30 秒后的本地提醒，确认应用 PID 已退出，随后从系统 NotificationManager 读取到「第999期 · 新建本期入学档案问卷」通知；没有重新打开界面。测试完成后清除测试会话、缓存与通知。
- 模拟器目视检查登录、今日卡片、阶段配色、底部导航和设置页面，截图保存在被 Git 忽略的 `artifacts/android/`。

## 交付与实际边界

release 启用 R8 与资源裁剪，使用本机个人安装签名。APK 及 SHA-256 由 `android/build.ps1` 生成在 `artifacts/android/`。签名密钥与凭据保存在用户目录且被排除在仓库外；不记录密码。

最终构建命令 `android/build.ps1` 成功，网站 19 项、安卓 13 项测试通过，lint 无问题。`apksigner verify --verbose --print-certs` 验证 APK Signature Scheme v2；`aapt dump badging` 确认包名、版本、SDK 范围与 ARM64 / ARM32 / x86 / x86_64 支持，release 未启用 debuggable。最终 APK 为 1,521,102 字节，SHA-256 为 `9a675fcb6d3fe76c248998f2a0baeb3a3fc625ff72038d5c9c2a355304f54acf`。最终 APK 已覆盖安装到 Android 15 模拟器并冷启动，最近一次启动后 crash buffer 为空；此前连续三次冷启动亦通过。此前卸载调试包后立即更换签名安装时出现过一次 Android 框架 Activity transaction 异常，重新冷启动及最终覆盖安装均未复现，堆栈没有应用代码帧。

真实小米手机没有连接，未声明通过 HyperOS/MIUI 锁屏、休眠或重启实测。模拟器未安装飞书，也没有使用真实账号，因此飞书真实文档的跳转与访问权限、真实账号登录和云端同步仍须在手机安装后验收。设备系统强制停止、未授权通知/精确闹钟以及后台省电限制仍以 Android/小米系统行为为准。

离线时只能使用最近同步的排期。云端改期、其他成员完成任务、访问权限变动，需要成功联网同步后反映到本机；不承诺后台实时推送。SOP 内容修改需要重新构建 APK；动态排期和完成状态不需要。
