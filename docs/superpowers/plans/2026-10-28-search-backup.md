# 话术搜索收藏与图文草稿备份

用户批准上一轮建议的两项迭代。本轮沿用下级菜单，无新主导航，不提交 / 推送 / 部署。

## 方案

- 网页和 App 子菜单默认“本任务”，另有“全部 / 收藏”，搜索覆盖 35 条的标题、分类、正文。仅显示折叠标题，正文点开才显示。
- 收藏按稳定话术 ID 保存在各设备，不缓存渲染后的日期，不增加云端同步。检索其他周话术时使用该话术实际关联的教学周，而不是把当前周日期套入第 12 周或考试通知。
- 网页草稿对话框内增加导出 / 导入。备份为自包含 JSON，包含多稿正文、原图、仓库、稳定 ID 和未知结果状态，不含账号凭据或已提交记录。导出先保存当前输入。
- 导入校验格式 / 数量 / 图片摘要及引用，完整通过后原子合并。重复相同稿跳过；相同 ID 内容不同则整批停止。保留当前稿，不自动提交、改投仓库或重建未知结果稿 ID。
