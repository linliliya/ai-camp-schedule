# 本地 SOP 知识库

用户最终选择：本地维护，界面沿用飞书式目录与正文阅读习惯；后续 AI 直接整理本地文件，用户手动同步飞书。无需飞书账号权限，不连接团队 Supabase，不推送 GitHub。

## 内容与运行方式

- `AI编程SOP/` 下的 Markdown 和相对路径附件为唯一原文，保留现有 8 份文件与图片/视频位置；阅读和索引不改写文件。
- 新增独立 `local-sop/` 应用，Python 标准库后台，仅监听 `127.0.0.1:8901`。静态前端本地打包，首次安装依赖后运行无需 CDN。
- 带目录导航、全文检索、正文目录、阅读/编辑、Markdown 源码模式、导出、历史与恢复；新建及收件箱可保存零散笔记，AI 再整理归入正式文档。
- 前端使用免费开源 Tiptap 编辑组件及现有 MiSans 原始字体。蓝色动作、浅灰左栏、白色正文、大标题和适度留白，与用户飞书截图的工作区结构相近。

## 文件保存与 AI 协作

每次保存带原文 SHA-256 版本；外部 AI 或第二窗口已修改则返回冲突，不覆盖当前编辑草稿。原始字节先留历史，再通过临时文件原子替换。历史在被 Git 忽略的本地状态目录，不参与内容检索。写入失败保留输入；浏览器也保留本机草稿。恢复历史同样生成备份并检查当前版本。

AI 可直接读取、编辑原始 Markdown，刷新后页面和搜索读取新文件。系统不声称具备未接入的大模型自动改写能力；收件箱是实际文件，使用说明给出可在聊天中调用的整理方式。用户确认前不把待讨论规则改进正式 SOP。

## 边界与验收

服务仅公开前端与 SOP 目录中的允许格式附件，不公开整个项目、签名或配置。写接口校验同源及本地 Host，文件路径必须位于内容根目录。首版提供新建、保存和历史恢复，保留原目录及附件位置。

测试用临时目录覆盖保存/重新读取、冲突、历史恢复、中文搜索、路径边界与失败后的文件完整性；实际原文仅核对内容哈希，不用测试夹具改写用户文档。验证窄屏导航、键盘搜索、编辑草稿、保存与外部修改检测。运行实际前端截图和一轮 Oil UI 独立评审（若浏览器执行受限，明确视觉验证缺口）。

新增维护规范及矛盾清单供用户处理，不自动改动原 8 份 SOP。日程新增第 3/11 周周三提醒作为并行已授权修改，第 12 周直播后安排保持原样。全部工作停留本地，不执行 Git 提交、推送、PR 或部署。
